# Weather App

A simple weather application built with React that allows users to search for a city and view its current weather information.

## Features

- Search weather by city name
- Display current temperature
- Display feels like temperature
- Display minimum temperature
- Display maximum temperature
- Display humidity
- Display weather condition
- Display wind speed
- Handle invalid city searches
- Responsive user interface
- Material UI components

## Technologies Used

- React
- JavaScript
- Material UI
- CSS
- OpenWeather API
- Vite

## API

This project uses the OpenWeather Current Weather API to fetch weather information.

The application sends the city name to the API and receives the current weather data.
